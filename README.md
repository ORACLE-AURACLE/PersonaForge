
# PersonaForge

**Talk to real people before they exist.**

PersonaForge is an AI platform that simulates realistic user personas to validate ideas, reduce wasted effort, and provide structured insights before building a product.


## Live Demo
- Demo: [https://persona-forge-alpha.vercel.app/]  
- Video: [https://youtu.be/aegqR373N4w?si=Fgjn43VOsxIobqg-]



## Key Features
- **Default Personas:** Casual Friend, Technical Expert, Professional Mentor, Creative Writer  
- **Custom Personas:** Define tone, personality, expertise, and behavior  
- **Persistent Memory:** Personas maintain conversation history  
- **Insights Panel:** Structured feedback separate from chat  



## How It Works
1. Pick a persona or create your own.  
2. Ask a question in chat.  
3. Get persona-specific responses.  
4. Review structured insights in the right panel.  



## Tech Stack
- **Frontend:** Next.js + React  
- **Backend:** Node.js  
- **AI:** Google Gemini 3 API  
- **Architecture:** Persona-isolated sessions  



## Achievements
- Multi-persona system with consistent memory  
- Clear chat vs insights separation  
- Four default personas with distinct behaviors  
- Stable Gemini 3 integration  



## Testing Instructions
- No login required.  
- Visit the live demo, select a persona, ask a question, see responses and insights.
